# Tesla Model 3 2018

Original model: [Tesla 2018 Model 3](https://sketchfab.com/3d-models/tesla-2018-model-3-5ef9b845aaf44203b6d04e2c677e444f) by [Ameer Studio](https://sketchfab.com/uchiha.321abc), licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Source copy: [jamesalmeida / tesla-infotainment](https://github.com/jamesalmeida/tesla-infotainment/blob/main/public/car-models/tesla-model-3-2018.glb). Its embedded metadata retains the original author's name, source and CC BY 4.0 license. The repository's MIT code license does not replace the vehicle's CC BY license.

Changes for Remo2: decoded Meshopt geometry, baked transforms, normalized to centimetres with +Z forward, corrected scale, separated the paired wheel meshes into four independently rotating wheel pivots, batched static geometry by material, simplified to 319,143 triangles with bounded error, retained source textures/interior, isolated headlight materials and enabled per-instance body paint. Prepared GLB: 7,303,640 bytes. Reproduction script: `prepare-model3.cjs` with glTF Transform 4.5.1 and meshoptimizer.

This is the 2018 exterior, not the Highland facelift. Dimensions and interior are approximate. The model is not an official Tesla asset and no endorsement is implied.
