# Qingpu map data

Roads, building positions, parks, water and station coordinates are derived from
© OpenStreetMap contributors, downloaded 2026-10-25 using the official OSM API.

Database license: [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Attribution and source: [OpenStreetMap copyright](https://www.openstreetmap.org/copyright).
The derivative database is `qingpu-map.json`; `prepare-city.cjs` describes conversion
from API XML. The in-game map also displays this attribution.

Building appearances, vehicles, signs and public-space proposals are original
procedural models; geographic data does not imply endorsement by depicted places.

The user's [Bao Tai In The Future reference](https://newhouse.591.com.tw/132815)
and its standard-floor plan / lobby illustration were inspected for spatial and
architectural reference. Those photographs and plan images are not redistributed
as game textures. Building facade textures are generated locally by the project.
