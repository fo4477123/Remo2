# B1 暖木日常

以 B1 公分座標平面為基礎的 WebGPU 室內設計與居家探索。線上版本：<https://fo4477123.github.io/Remo2/>。

本輪依使用者選擇採WebGPU網頁路線：Three.js 0.186.1原生WebGPU、SSGI間接光／接觸陰影、時間抗鋸齒、2K本地掃描材質、外部現代家具及更細緻床品。無WebGPU裝置時明確切換WebGL2相容模式；頁首及顯示設定會標示實際後端。完整範圍與品質界線見 [WEBGPU-REMAKE.md](WEBGPU-REMAKE.md)。

## 操作

- 按「開始探索」，或從房間選單前往空間。
- 「♫ 舒心配樂」可播放Scott Buckley的Reverie／Childhood、切換曲目與音量。預設不自動播放；離開分頁暫停、回來恢復，手札亦可開關配樂。曲目與授權標示均可見。
- 客廳使用已確認的暖嶼家居伴木220 × 106 cm客製款，兩側靠背可分別前後移，插銷頭枕可換側；主臥為上掀收納床。次臥右側新增雪板／護具收納，可拉出雪板查看。參考與驗收見 [OWNED-FURNITURE.md](OWNED-FURNITURE.md)。
- 八項居家任務、七項原有大廳委託、八項鄰里委託、一項 B3-31 車位委託與四項城市委託，合計28張收藏。完成後記憶牆逐步豐富、顯示獎勵特效並增加客廳擺飾；新玩家全部領取後解鎖「R & Y Sweet Home」公仔，舊版已解鎖者保留。
- 使用者住宅為 **B1-5F**；同側 **B3-5F**，走道另一側 **B2-5F／B5-5F**。兩棟各層四戶雙梯、兩戶三房與兩戶兩房；一樓共用大廳連結健身房、小圖書館、琴房、鼓室，B3地下停車場含專屬 **B3-31**。按 E 對話、選樓、操作設施；社區導覽亦可快速換區。公共配置依描述建模，未提供部分為空間提案。
- 七位 NPC 提供對話和委託：秘書、鄰居、教練、閱讀志工、鋼琴與鼓手。包裹需領取後配送，書籍可挑選借還；跑步機與單車有三次節奏挑戰，鋼琴和鼓室有四音／四拍互動及合成音效。B3-31可定位、控制尋位燈與車擋。詳見 [社區擴充規格](COMMUNITY-EXPANSION.md)。
- 青埔城市地圖依本地 OSM 資料建立2288筆道路與2106筆建物資料，地標位置核對官方資訊。可從大廳出門或 B3-31 開車；支援汽車、機車、YouBike、街道路徑導航及 A17～A19 遊戲列車。含桃園高鐵、環球 A19、美術館園區、兒童美術館、橫山書法公園、陽光劇場與 IKEA。模型外觀及交通時間為遊戲化呈現；官方尚未開放的母館標為建築展望。操作：W／S加減速、A／D轉向、Space煞車、F上下車、M地圖、H車燈；手機沿用搖桿與操作按鈕。詳見 [城市章節](CITY-CHAPTER.md)。
- 街區預設第三人稱，原創Q版主人公具髮型、外套、斜背包與球鞋，支援行走、跑步及騎乘姿勢。住宅與社區按V或畫面按鈕切換第一／第三人稱並記憶偏好。商家圖資312筆，其中310間商家整合為282組可探索店面；地圖可搜尋商家、導航、店員對話及收集店章。
- 島語茶几依官方介紹圖重製為收合80 × 60 × 53 cm／展開80 × 120 × 74 cm，具有翻折桌板、平行升降連桿、單面單抽屜＋雙收納凳／背面開放格＋雙抽屜。凳面可上掀，茶杯高度同步，手札可直接操作。詳見 [已購家具](OWNED-FURNITURE.md)。
- 桌面用 WASD／方向鍵移動、拖曳轉頭；靠近並面向物件後按 E。J 開啟手札，Esc 釋放滑鼠／退出漫遊。
- 手機用左下搖桿與另一指轉頭，點畫面提示操作；沉浸模式內可直接打開手札。
- 可操作大門、客衛隱藏門、清潔櫃、主臥滑門衣櫥、電器櫃、升降桌、電視及餐桌。
- 新增三組窗簾、冰箱雙門與內燈、洗衣機轉動、水龍頭水流及三區燈光。手札內的「生活控制」也可直接操作設備；洗衣運轉示範 45 秒、水流 90 秒後會自動停止。
- 一般室內淨高 280 cm、廚房245 cm，牆頂、門楣及連續天花／樓板補齊。沙發、雙臥床具、網布椅與茶几重建；全室所有家具與設備類別均套用表面及構造細節升級，另含本地 CC0 掃描材質。
- 冰箱外尺寸校正為 72.1 × 69.5 × 183.4 cm；電器櫃改為 58.5 × 60 cm，檯面調為 230 × 60 cm。沿檯面往側牆依序為電器櫃、冰箱，配置限制在 CAD 背牆與側牆內。主臥衣櫥由275 cm減少20 cm為255 cm。
- 廚房淨高245 cm，電器櫃同步降低；冰箱上方可開門置物，多功能室臥榻可上掀收納。客衛修正地坪誤判碰撞與 CAD 設備線誤建實牆，玻璃門可開關、淋浴區可走入操作花灑。示範水流與加熱離家後也會計時關閉，不會強制將玩家傳回住宅。
- 收集九個住宅空間與八個居家任務；進度僅存於本機，手札內可重設門櫃、設備、光線及進度。手札及首頁均可選晨光、夕暮、夜間；提示音預設關閉。
- 居家任務與社區委託提供經驗、生活點及實際客廳收藏。委託需接取並完成條件才可領取；重載或重複操作不會重複累加。原有存檔與獎勵 ID 保留，車位狀態和隨身物品也會存檔。
- 窗外以青埔八街與九街路口、五樓高度製作連續環景，客廳朝高鐵桃園站，後側對應青松街。這是區域景觀模擬，建物遮擋與外牆並非本戶實拍。來源與生成提示見 [ASSET-SOURCES.md](ASSET-SOURCES.md)。
- 一樓大廳有獨立人行道高度窗景；住宅使用五樓窗景。圖片載入失敗會讀取本地備援，設定內也可重新載入窗景。

## 執行與驗證

純靜態網站，不需要打包。使用靜態HTTP伺服器提供本目錄，從localhost或HTTPS開啟 `index.html`；ES modules需要HTTP載入，不支援直接開啟file網址。`nordic-studio.html` 使用同一套程式。`?renderer=webgl` 可明確選用相容模式。

`node qa-community.cjs` 驗證本輪花灑路徑、公共區域可達性、NPC、電梯、包裹、借還書、樂器與健身挑戰、車位互動、獎勵及手機介面；設定 `B1_RENDERER=webgpu` 可要求真實 WebGPU 後端。截圖與報告寫入已忽略的 `qa-output/run-*`。

`node qa-city.cjs` 驗證三種載具的真實按鍵移動、地圖路徑、A17～A19列車、地標活動、城市委託、樂器／健身鍵盤操作、手機及舊公仔存檔相容。`node qa-islewhisper.cjs` 驗證茶几實際模型尺寸、升降翻折、三抽屜、雙凳與茶杯高度；同樣可設定 `B1_RENDERER=webgpu`。

舊版 `qa-home.cjs` 與 `qa-render.cjs` 保留先前固定互動數量及任務數的斷言，尚未更新至本輪28張收藏，不能用其固定數量作為本輪驗收。這一輪使用上面的三支章節測試，涵蓋實際 WebGPU／WebGL2、互動、任務存檔、手機版面及室內第三人稱鏡頭遮擋。

WebGPU章節測試必須實際初始化WebGPU後端，無adapter時明確失敗，不將WebGL2當成成功。測試旗標僅用於隔離的本機測試瀏覽器，不會修改使用者瀏覽器設定。

核心模型、材質與渲染不依賴外站。`?assets=remote` 為原有外部床具與木地板素材的選用預覽；可用性取決於供應站，載入失敗會保留本地模型。沒有將網站內的模型宣稱為全數外部高精細資產。

## 結構與界線

`studio-engine.js` 初始化實際繪圖後端；`studio.js` 建立幾何與公分座標；`studio-detail.js` 補充空間；`studio-finishes.js` 建立材質與環景；`studio-home.js` 處理手機、圖庫與效能；`studio-render.js` 提供WebGPU的TSL／SSGI／抗鋸齒管線與相容PBR；`studio-models.js`、`studio-refine.js`、`studio-remake.js` 建立及細化模型、材質與LOD；`studio-shell.js` 補齊封閉結構；`studio-life.js`、`studio-activities.js` 提供居家設備；`studio-neighborhood.js` 建立廊廳、公設、停車場與角色；`studio-community.js` 提供對話、練習、交通、委託與收藏；`studio-game.js` 統一互動與探索狀態；`studio-music.js` 控制本地授權配樂。

WebGPU高畫質與WebGL2相容模式各自有明確後端標示。FF7 Remake是美術方向參考，不代表已取得該遊戲資產或達到同等製作規模；本案沒有使用UE4、DLSS或原遊戲配樂。圖庫的生成圖是材質／氣氛提案，不能取代平面圖或施工放樣。第一張客廳圖保留；第二張走道修正詳見 [RENDER-CORRECTION.md](RENDER-CORRECTION.md)。

推送 `master` 後由 GitHub Pages 自動部署；應確認該次 Pages 工作流程成功及線上資源版本。

低功耗筆電與整合顯示卡可用「GPU 調校」選單選擇自動省電、整合顯示卡、平衡或畫質優先。WebGPU會優先選低功耗adapter，自動模式依GPU資訊調整解析度和模型細節；可切回畫質優先。
